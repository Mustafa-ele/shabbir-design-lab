# Shabbir Design Lab

A GitHub Pages-ready static blog starter for original UI/UX, app, AI and web-development articles.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/ (root)` as the source if that option is shown.
5. Save and open the published URL.

GitHub Pages can publish static HTML/CSS/JS directly from a repository.

## Before monetization

- Replace `your-email@example.com`.
- Add your real About/Contact details.
- Customize Privacy Policy and Terms for the actual services you use.
- Publish substantial original articles.
- Add your own analytics/advertising code only when you are ready and have reviewed the relevant policies.
- Do not copy other websites' articles or images without permission.
